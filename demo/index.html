msdfgen-ts — demos

TypeScript port of Chlumsky/msdfgen — runtime MSDF atlas generation, no WASM. Source.

  • CPU canvas fallbackreference

    One atlas, several output sizes, reconstructed on the CPU with 2D canvas — no GPU needed.

  • WebGPU rendererM5

    The real deliverable: instanced-quad WGSL median shader. Static render for now.

  • WebGPU pan/zoominteractive

    Drag to pan, wheel/pinch to zoom toward the cursor, with a resolution selector (24/32/48/64px) to compare atlas tiers at the same view.

  • WebGL2 pan/zoominteractive

    Same pan/zoom + resolution selector as above, over WebGL2 — for browsers/CI without a WebGPU adapter.

  • WebGL2 test renderertest-only

    Same instanced-quad renderer as the WebGPU demo, for browsers/CI without a WebGPU adapter.

  • MSDF debug viewdev tool

    Per-glyph vector/RGB/channel/median panels — for inspecting coloring and error-correction.
