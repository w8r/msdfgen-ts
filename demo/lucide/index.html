msdfgen-ts — every glyph in Lucide.ttf

Lucide is an icon font: ~1745 pictogram glyphs, almost none of them reachable through a normal Unicode codepoint (its cmap only maps a handful of ASCII characters — this font is deliberately in the test corpus for exactly that reason). Rendered here via Atlas.glyphsByIndex() — raw glyph-index addressing, the codepoint-free twin of Atlas.glyphs() — one glyph per grid cell, scale-to-fit, using the same bilinear MSDF reconstruction as the canvas demo. Generated in chunks (not all at once) so the tab stays responsive; fills in progressively.
