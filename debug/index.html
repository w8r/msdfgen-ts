MSDF debug view

Every row is one glyph, generated into a small MSDF cell (default 16×16 texels, pxrange 4) and shown at 200×200. All six views share the same cell-space transform, so features line up pixel-for-pixel — useful for spotting coloring bugs, error-correction glitches, and channel misalignment. The median column reconstructs opacity the way a real MSDF text shader does (median(r,g,b) − 0.5, clamped after scaling).
